# AI 声鉴所 · 测评结果分析设计文档

> 产品定位：30 秒，鉴定你的声音灵魂。
> 产品公式：**用户愿意输入的自我（声音）→ 输出一个可佩戴的标签（声音人格）**。

## 0. 设计逻辑推演（五步法速览）

**① 多维拆解**：本产品成立靠三个维度——
- **情绪维度**：卖的不是"分数"是"被确认"（声音是第二张脸，用户极少被认真夸过声音）；
- **社交维度**：分享图是产品本体，输出必须是"可转发的自我素材"；
- **结构维度**：一次输入 → 专属输出，测评只是采集个性化素材的 prompt。

**② 正反推演**：
- 乐观：声音测评情绪浓度高（"第一次有人认真夸我的声音"）、输入零羞耻感（录音不用露脸）、输出有新鲜感（人格标签 + 估值）；
- 悲观：AI 听不准音色细节会让"专业感"崩塌；纯彩虹屁会腻。→ **对策**：前端本地做真实声学测量（音高/明亮度/语速/停顿/动态），让报告"有数据可依"，专业感来自透明的过程而非玄话；夸奖必须"具体到引用原话"。

**③ 深度质疑**：
1. 用户分享的是"我"还是"梗"？→ 两条都要：结果精致可晒（我），称号/估值可玩梗（梗）。
2. 夸不到位怎么办？→ 引用录音原话（ASR 式转写）+ 客观声学数据，把"泛夸"变"定制夸"。
3. 复制边界？→ 声音满足三条件：输入愿意（无羞耻）、期待输出（自我相关高）、愿意晒（声音内容天然适配短视频生态）。

**④ 全局复盘**：修正——不是"语音评测工具"，是"个性化内容生成器"；分数只是排版道具，人格标签和估值才是分享货币。

**⑤ 终态结论**：本设计以"真实声学测量 + AI 听感 + 彩虹屁话术工程"三层叠加，输出"声音人格 + 估值 + 击败率"三件套分享钩子；前置条件是结果整体右偏（只夸不贬）与合规红线（不涉医疗断言、不涉容貌焦虑、录音不存储）。

## 1. 测评输入设计

- 三选一朗读文案（覆盖不同声音气质的表达场景）：
  1. 晚安电台 · 治愈系 🌙
  2. 古风独白 · 文艺系 🏮
  3. 元气播报 · 活力系 ⚡
- 时长建议 15–30 秒（最短 5 秒可提交，40 秒自动截断）。

## 2. 双层分析引擎（本产品的"专业感"来源）

### 第一层：浏览器本地声学测量（Web Audio API，透明可信）
| 特征 | 方法 | 报告中的作用 |
|---|---|---|
| 平均音高 F0 | 逐帧自相关 (8kHz 下采样) | 推断声线高低区 |
| 音高波动 | 基频半音标准差 | 抑扬顿挫程度 |
| 明亮度 | 过零率映射 | 音色冷暖 |
| 语速 | 能量包络峰值计数（音节/秒） | 节奏感 |
| 停顿占比 | 静音帧比例 | 从容感/呼吸感 |
| 响度动态 | 语音段 RMS p90/p10 (dB) | 感染力 |

### 第二层：AI 全模态深度分析（qwen3.8-omni-flash @ 阿里云百炼）
- 直接"听"录音：转写原话 + 感受音色质感、情绪温度、表达习惯；
- 与本地声学特征交叉验证后输出结构化 JSON（人格/五维分/诊断书/场景/建议）。

## 3. 结果结构（结果页自上而下）

1. **声音人格主牌**：emoji + 人格名 + 专属称号（如「被天使吻过的喉咙 No.7321」）+ 一句话人设
2. **两大钩子数据**：
   - 声音估值：`¥600–26,600 / 15s 商业配音`（由综合分右偏映射，人人不低）
   - 全国击败率：`30%–99.9%`（与估值同源，制造比较欲）
3. **五维声音雷达**（72–98 分右偏区间）：
   - 音色魅力（好听耐听）/ 感染力（情绪浓度）/ 节奏感（语速停顿掌控）/ 辨识度（记忆点）/ 亲和力（治愈度）
4. **AI 声学诊断书**（三段彩虹屁，必须具体）：
   - quote：**引用录音原话**的夸奖（让用户确信"AI 真的在听我说话"）
   - 音色印象 / 表达高光 / 隐藏彩蛋
5. **隐藏款人格**：气质互补的副人格（制造二次测试欲）
6. **声音主场**：3 个最匹配的声音场景/职业（播客主播/晚安电台/纪录片配音…）
7. **声音使用说明书**：2 条可操作建议（实用钩子，留住"下次再来"）

## 5. 分享机制设计

- **分享卡片**：1080×1440 竖版 canvas 生成图——深色渐变 + 玻璃质感，人格名大字、五维雷达、估值金色大字、击败率进度条、引用金句、站点链接（自带传播入口）。
- **分享文案模板**：`我在【AI 声鉴所】测出了「深夜电台主理人」声音人格！AI 估值我的声音 ¥8,800/条，击败了全国 91.2% 的声音🔊 你也来测测你的声音值多少钱 → {url}`
- **分享通道**：移动端优先 `navigator.share`（带图分享到微信/小红书），桌面端自动下载 PNG + 复制文案。
- **再测一次**：一键回到录音页（保留当前文案）；另提供「换个文案再测」入口（换输入 → 换结果 → 二次传播素材）。

## 6. 情绪安全与合规设计

- 所有维度 ≥72 分，低分维度表述为"隐藏款/待开发彩蛋"，**只夸不贬**；
- 不做性别预设与外貌评价，文案主语一律"你"；
- 录音仅用于本次分析，不做存储（Worker 收到即分析即丢弃，无日志无落盘）；
- 页面脚注：结果由 AI 生成，仅供娱乐；
- 不涉医疗/心理断言，不涉玄学命理红线。

## 7. 技术架构

```
浏览器 (GitHub Pages 静态站)
 ├─ 录音 MediaRecorder → 解码重采样 16kHz WAV (base64 ~1MB)
 ├─ 本地声纹特征提取（Web Audio API）
 └─ POST {audioBase64, features, ...}
        ↓
Cloudflare Worker (voice-aura-api)
 ├─ CORS 校验 + 频率限制 + 体积校验
 ├─ 调用 阿里云百炼 DashScope（OpenAI 兼容）
 │    model: qwen3.8-omni-flash（最新全模态，原生音频理解）
 │    input_audio: { data: <base64>, format: "wav" }
 ├─ 解析/清洗/归一化（分数钳制、估值与击败率确定性映射）
 └─ 返回结构化 JSON（密钥仅存 Worker Secret，绝不进前端）
```
